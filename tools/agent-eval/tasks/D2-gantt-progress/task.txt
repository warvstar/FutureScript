Add `fn percentDone(p: Project): num` to main.fut (not pub). It returns how much of the project is finished, as a percentage weighted by duration: the durationDays of the done tasks over the durationDays of all tasks, times 100, rounded to the nearest whole number with `math.round` from std/math. A project with no tasks (or whose tasks total 0 days) is 0. For example, in `demoProject()` with "design" and "docs" done, it is 25.

Add a test for it in main.fut. `fut test main.fut` must pass when you finish.
