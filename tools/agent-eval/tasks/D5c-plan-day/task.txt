Add `fn planDay(p: Project, slots: num): list<str>` to main.fut (not pub). It returns a line for each of the first `slots` tasks that are ready to start (not done, with every dep done), in project order: `"<id> (<assignee>)"`, or `"<id> (unassigned)"` when the task has no assignee. If fewer than `slots` tasks are ready, it lists just those. For example, in `demoProject()` with "design" done and "backend" assigned to bo, `planDay(p, 2)` is `["backend (bo)", "frontend (unassigned)"]`.

Add a test for it in main.fut. `fut test main.fut` must pass when you finish.
